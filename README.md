# MotoGuard Sensor de Impacto
Sistema inteligente para detecção de impactos, que envia alertas diretamente para o aplicativo do usuário.

## Tecnologias Utilizadas
C++ – Linguagem principal utilizada no desenvolvimento via Arduino IDE.

ESP32-C3 Mini – Microcontrolador de alta performance com conectividade Wi-Fi e BLE.

MPU-9250 – Sensor de movimento (acelerômetro, giroscópio e magnetômetro) para detecção precisa de impactos.

TP4056 – Módulo para carregamento de bateria.
